## 👨‍💻 Sobre mí

Estoy construyendo mi camino hacia mi primer puesto como **desarrollador Java trainee o junior**. Mi forma favorita de aprender es tomar una necesidad real, convertirla en un proyecto y entender cada decisión técnica en el proceso.

Actualmente estoy fortaleciendo fundamentos de Java, programación orientada a objetos, colecciones, Maven, pruebas y aplicaciones de escritorio. No quiero solo que el código funcione: quiero saber por qué funciona y cómo mejorarlo.
